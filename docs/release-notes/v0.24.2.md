# L Harness v0.24.2

画像・Flexの入力欄と、最大5件のメッセージをまとめて送る機能を追加しました。

- 一斉配信、シナリオ、リマインダーで、選んだ種類に応じて文章・画像アップロード／URL・Flex JSONの入力欄が切り替わります。
- テキスト・画像・Flexを最大5件まで混在させ、追加・削除・並び替えできます。
- 個別チャットの「複数・Flex」からまとめて返信できます。従来の画像＋文章も1回の送信にまとめます。
- 送信順序を保ち、受信者1人につき1回のAPI呼び出し・送信ログとして扱います。名前の差し込みとリンク計測は各メッセージに適用します。
- 従来の1件のメッセージはそのまま利用できます。今回追加のDBマイグレーションはありません。

## 更新方法

保存済み設定のあるインストール先で実行してください。標準の `~/.line-harness` を使う場合は `--repo-dir` を省略できます。

```sh
npx create-line-harness@0.2.12 update --repo-dir "/path/to/existing/install"
```

Workerと管理画面をセットで更新してください。手動デプロイはWorkerを先に公開します。
複数メッセージを保存した後は、旧Workerだけへ戻さないでください。

## 検証

送信APIを置き換えた結合テストで、5件の順序、1回の呼び出し、1行のログ、6件の拒否、アカウント分離、重複除外、シナリオ・リマインダーの実行と再実行を検証しています。
入力欄とプレビューはReactのサーバーレンダリングで検証しています。実際の友だちへのLINE送信、ブラウザ操作による検証は行っていません。
